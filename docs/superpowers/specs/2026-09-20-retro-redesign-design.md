# 레트로 윈도우 스킨 리디자인 설계

날짜: 2026-09-20
참고 자료: `웹사이트작업/화면/*.jpg`, `웹사이트작업/버튼 에셋들/*`, `웹사이트작업/캐릭터/*.png`

## 배경 및 목표

현재 사이트는 흰 배경 + 세리프 폰트의 미니멀 매거진 스타일이다. `웹사이트작업/` 폴더에 모아둔 레퍼런스 스크린샷은 Windows XP 시절 느낌의 레트로 UI(파란 그라데이션 제목바, 크림색 사이드바, 각진 스크롤바/버튼)이며, 세부 인터랙션도 몇 가지 다르다:

- 검색은 팝업이 아니라 우측 콘텐츠 패널 안에서 전환된다.
- 별점은 녹음 완료 후 순차 입력하는 게 아니라, 상세 화면의 "총점"을 클릭하면 뜨는 팝업에서 언제든 조회/입력한다.
- 녹음 시작 전에 "독서모임 시작 전" 선택지 화면과 "수칙 말하기" 화면 2단계를 거친다.
- 녹음 중에는 책 모양 길잡이 캐릭터가 화면 우측 하단에 상주하며, 목소리 크기(데시벨)에 따라 다른 대사/색상으로 반응한다.

전체 방향은 사용자 승인 완료: **비주얼은 레트로 스킨으로 전면 교체**, **제공된 버튼/캐릭터 png 에셋을 그대로 사용**, **캐릭터 상태 전환은 기존 `decibelMonitor.js`의 데시벨 분류를 기준으로 자동화**, **로고/배경 이미지(`assets/logo.png`, `assets/back.jpg`)는 기존 유지**.

## 범위 밖 (Out of scope)

- 백엔드/Firebase 데이터 모델 변경. 리뷰·책·모임 데이터 구조는 그대로 두고 UI/UX만 바꾼다.
- `decibelMonitor.js`, `decibel.js`의 데시벨 측정 로직 자체 변경. 이번 작업은 분류 결과를 소비하는 UI 레이어만 추가한다.
- 로고(`assets/logo.png`)·배경(`assets/back.jpg`) 이미지 교체 (기존 유지하기로 확정).
- 커스텀 스크롤바 화살표 버튼의 완벽한 픽셀 재현 (톤만 맞추고, 기능은 네이티브 스크롤 사용).

## A. 비주얼 시스템 (레트로 윈도우 스킨)

- **컬러 토큰 재정의**: `css/style.css`의 `:root` 변수(`--ink`, `--muted`, `--line`, `--paper`, `--panel` 등)를 레트로 팔레트로 교체.
  - 제목바: 파란 그라데이션 (`#4A6FC0` → `#8FB3F0` 계열, 레퍼런스 색 추출)
  - 사이드바/앱 배경: 크림색 (`#EDE8DC` 톤)
  - 콘텐츠 패널: 흰 배경 + 회색 각진 테두리(`border: 2px solid #999`, 그림자 없음 또는 최소 inset shadow)
- **레이아웃**: 기존 `.main-layout`(사이드바 `main-left` + 콘텐츠 `month-detail`) 2단 구조를 그대로 재사용. 상단에 새 제목바(`책 쫌 읽읍시다` + 우측 `?` 버튼) 추가.
- **폰트**: 레퍼런스는 고정폭 도트 느낌 폰트. 무료 대체(예: 구글 폰트 중 고정폭/픽셀 계열, 없으면 시스템 모노스페이스로 폴백)로 근접 적용. 기존 `Ridibatang` 폰트는 제거.
- **버튼**: `웹사이트작업/버튼 에셋들/버튼_선택전/*`, `버튼_선택후/*` png를 `assets/buttons/`로 복사해 배경 이미지로 사용. `:hover`/`:active` 시 선택후 이미지로 전환.
- **스크롤바**: 콘텐츠 패널과 사이드바 리스트에 시각적으로 각진 스크롤바 느낌을 CSS(`::-webkit-scrollbar` 커스터마이징, 파이어폭스는 `scrollbar-color`)로 근접 재현. 화살표 버튼은 생략.

## B. 화면 구조 변경

- `screen-search`, `screen-detail`가 현재 전체 화면을 덮는 `.book-screen` 오버레이(팝업형)로 되어 있는데, 이를 **사이드바는 유지한 채 우측 콘텐츠 패널(`month-detail`) 내부 뷰 전환**으로 바꾼다.
  - 검색 버튼 클릭 → 우측 패널이 검색 뷰로 교체 (상단 검색 인풋 + 검색 버튼 + 결과 리스트, 사이드바는 그대로).
  - 검색 결과 "선택" 클릭 → 우측 패널이 상세 뷰로 교체.
  - "✕" 닫기 버튼은 제거하고, 사이드바에서 다른 달/책을 클릭하면 자연스럽게 뷰가 바뀌는 방식 유지.
- 상세 화면(`detail-analyzed-content`)에 레퍼런스에 맞춰 필드 추가:
  - 상단 우측에 "공유 · 수정 · 삭제" 텍스트 링크 (기존 기능 있으면 연결, 없으면 자리만 마련 후 no-op)
  - "총점" 줄: 별 5개 + 평균 점수 숫자, 클릭 가능 (C 섹션 팝업 트리거)
  - "토론시간" 필드 (녹음 길이 표시, 기존 데이터에 있으면 사용)
  - "날짜" 필드 (모임 날짜)
  - 없는 데이터는 필드 자체를 숨김 처리 (빈 값 노출 금지)

## C. 별점 팝업

- 상세 화면의 "총점" 영역 클릭 시 모달 팝업 오픈 (레퍼런스 "감상평 이야기 창" 참고):
  - 팝업 상단: `[이름]의 감상평 : ★★★★★` 형식으로 기존 리뷰 목록을 스크롤 가능한 리스트로 표시
  - 팝업 하단: 이름 입력 인풋 + 별점 선택(클릭 가능한 별 5개) + "보내기" 버튼 → 제출 시 리뷰 목록에 즉시 추가되고 평균 점수 갱신
  - 팝업 닫기: 상단 우측 ✕ 아이콘
- **플로우 변경**: 현재 `mainView = 'review-entry'`로 녹음 완료 후 강제로 리뷰 입력 단계를 거치는 로직을 제거. 녹음 완료 → 분석 결과(요약 등) 화면으로 바로 이동. 리뷰는 총점 팝업에서 언제든 자유롭게 추가.
- 기존 `calcAverage` (js/ratings.js)는 그대로 재사용.

## D. 녹음 시작 전 흐름 (신규 2단계)

1. **독서모임 시작 전 화면** (레퍼런스 "웹사이트작업-07"): 상세 화면에서 "독서모임 시작!" 버튼 클릭 시, 우측 패널 하단에 캐릭터(책5_도움 또는 책6_인사) 말풍선이 뜨며 "무슨 말을 해야할까요? / 그냥 시작할게" 두 선택지 제공.
   - 어느 쪽을 선택하든 다음 단계(수칙 화면)로는 반드시 넘어간다. "무슨 말을 해야할까요?" 선택 시에만 대화 예시(웹사이트작업-08 참고 문구: "어떻게 읽었는지 서로 이야기해보기" 등)를 캐릭터가 추가로 보여주고, "그냥 시작할게"는 그 설명 없이 바로 다음 단계로 넘어간다는 차이만 있다.
2. **수칙 말하기 화면** (레퍼런스 "수칙말하기 창"): 기존 `bookSlider.js`의 `MEETING_RULES` 배열을 재사용. 초록 그라데이션 배경 위에 수칙 5개 나열 + "진짜 시작하기!" 버튼. 버튼 클릭 시 실제 녹음(`recorder.js` 시작 로직) 트리거.

## E. 녹음 중 길잡이 캐릭터 (데시벨 기반 상태머신)

새 모듈 `js/guideCharacter.js`를 추가해 `decibelMonitor.js`의 콜백(`quiet` / `moderate` / `loud`)을 구독하고, 지속 시간을 자체적으로 타이머로 누적해 아래 상태로 전환한다. 데시벨 측정/분류 로직 자체는 변경하지 않는다.

| 상태 | 트리거 조건 | 캐릭터 | 콘텐츠 박스 배경 | 대사 |
|---|---|---|---|---|
| idle-help | `quiet` 8초 이상 지속 | 책5_도움 | 흰색(기본) | "혹시 제가 필요할까요? / 무슨 말을 해야할까요? / 어떻게 시작해야돼? / 그냥 시작할게" |
| encourage | `moderate` 상태에서 간헐적(예: 30초 주기) | 책4_응원 또는 책7_엄지척 | 흰색(기본) | "우와!! 지금 너무 좋은데요!! 서로 말도 잘하고 계세용!" |
| warn-loud | `loud` 5초 이상 지속 | 책2_궁금 | 주황 그라데이션 | "지금 너무 격해졌어요, 잠깐 쉬었다 해보세요!!" |
| block-fight | `loud` 15초 이상 지속(경고 후에도 계속) | 책1_금지 | 핑크 그라데이션 | "건전한 독서모임을 위한 수칙" 재노출 + "다시 시작하기!" 버튼 |

- `block-fight` 상태에서 "다시 시작하기!" 클릭 시 D-2단계(수칙 화면)로 되돌아간다 (녹음은 일시정지 또는 리셋 — 구현 단계에서 기존 `recorder.js` API 확인 후 결정).
- 임계값(8초/30초/5초/15초)은 상수로 분리해 조정 가능하게 한다.
- 캐릭터는 우측 하단에 고정 배치, 말풍선은 좌측에 위치 (레퍼런스 레이아웃과 동일).

## F. 에셋 정리

- `웹사이트작업/버튼 에셋들/버튼_선택전/*`, `버튼_선택후/*`, `에셋들/*` → `assets/buttons/`로 복사
- `웹사이트작업/캐릭터/*.png` (책1_금지 ~ 책7_엄지척) → `assets/characters/`로 복사
- 기존 `assets/logo.png`, `assets/back.jpg`는 변경하지 않음.
- `웹사이트작업/` 원본 작업 폴더는 참고용으로 그대로 두고 삭제하지 않는다.

## 영향받는 기존 파일

- `css/style.css`: 컬러 토큰, 레이아웃, 버튼/스크롤바 스타일 전면 수정
- `index.html`: 제목바 마크업 추가, `screen-search`/`screen-detail`를 오버레이 대신 콘텐츠 패널 내부 뷰로 재구성, 별점 팝업 마크업, 시작 전/수칙 화면 마크업, 길잡이 캐릭터 마크업 추가
- `js/app.js`: 화면 전환 로직(`mainView` 상태), 리뷰 입력 플로우 분리, 팝업 오픈/클로즈 핸들러 추가
- `js/bookSlider.js`: `MEETING_RULES` 재사용 (문구 확정 필요 시 조정)
- `js/screens.js`: 콘텐츠 패널 내부 뷰 전환 유틸 추가 가능성
- 신규: `js/guideCharacter.js`

## 테스트/검증 방법

- 로컬 서버로 실행 후 브라우저에서 실제 흐름 확인: 검색 → 상세 → 총점 팝업 → 리뷰 추가 → 독서모임 시작 → 수칙 → 녹음 시작 → (마이크 입력으로) 조용함/보통/큰 소리 상태 각각 재현해 캐릭터 반응 확인.
- 기존 Firebase 연동(`firebase.js`)과 녹음 업로드(`recorder.js`) 로직은 변경하지 않으므로 회귀 테스트 위주로 확인.
